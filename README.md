В Модуле 1 разработана база данных в 3НФ, спроектирована ER-диаграмма и создан скрипт инициализации базы.
В Модуле 2 реализован алгоритм работы приложения и создано окно авторизации с разграничением прав доступа (гость, клиент, менеджер, администратор). 
В Модуле 3 разработан пользовательский интерфейс с возможностью фильтрации, сортировки и поиска товаров, а также реализована форма добавления и редактирования товаров с валидацией ввода.
В Модуле 4 реализован интерфейс для работы с заказами. Все поставленные задачи выполнены в полном объеме
